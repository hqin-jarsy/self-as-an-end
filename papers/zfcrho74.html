Abstract

This paper closes the stage of ZFCρ Papers L–LXXIII and delivers two groups of results.

The first group consists of unconditional arithmetic facts about the recursion itself; no originality is claimed for them. Writing $c(n)=\rho_{\mathcal D}(n)+2$ turns the factor candidates additive in $c$, and yields Theorem 74.A: $c(n)\ge\alpha\log n$ for all $n\ge1$, with $\alpha=5/\log 4=3.6067\ldots$, and Theorem 74.A′: equality holds exactly at $n=4^k$. Corollaries follow: $c(4^k)=5k$ and $\liminf_n\rho_{\mathcal D}(n)/\log n=5/\log4$; the capacity constant $\gamma=\lim_K\log A(K)/K=\log4/5=1/\alpha$, where $A(K)=\max\{n:c(n)\le K\}$, together with the exact capacity points $A(5k)=4^k$; and the closed form $c(2^m)=\lceil 5m/2\rceil$, whose increments alternate between $2$ and $3$ from $m\ge2$. These follow from the defining recursion alone, independently of any centering constant, prime sampling, or spectral apparatus.

Antecedent. The function $\rho_{\mathcal D}$ and the shortest-representation complexity $d$ of Dogra (2018) over the operator set $\{1,S,\times\}$ satisfy $d=\rho_{\mathcal D}+1$; that paper already reports the lower bound and the equality case. No originality is claimed for the first group; what is offered is an independent proof in the min-plus normalization. This antecedent was not cited in the papers of the series that used the model.

The second group audits the current specification of Conjecture 59.1. An exact identity factors the weighted ratio $R_{\rm wt}(j)=B_j^2/(jD_j)$ into a purely arithmetic factor and a purely statistical one, with no distributional hypothesis. It shows that exact centering is a necessary condition for 59.1 and an extremely rigid one: inverting the published measurements gives the normalized requirement $|\varepsilon|/\sqrt{Q^{(2)}_{32}}\lesssim3.0\times10^{-5}$; conditionally on the value $\sqrt{Q^{(2)}}\approx0.75$ measured here at lower blocks, this is an absolute precision of roughly $2.3\times10^{-5}$, some $3.3$ orders of magnitude below the $\pm0.05$ spread attainable by extrapolation. Proposition 74.C (unconditional): with $\mu_{12}$ fixed, at most one $\lambda$ can render the weighted ratio bounded. Proposition 74.D (unconditional): well-posedness of $\mu_{12}$ under its own limit definition forces the centering slope to be unique — but that uniqueness does not by itself deliver $\mu_{12}$, since existence of a slope does not entail convergence of the centered class means. On this basis "59.1" is separated into five versions of distinct logical status.

Thirty-three published anchor values are checked against the tables used here (33/33), and one upstream erratum is registered. Parts §3 and §4 are a handoff and a register of exploratory observations; they carry no load. Their empirical findings were all executed before being stated and therefore have no confirmatory standing; the single pre-registered item is handed off along with the open problems.

§0 Object, Notation, and Instrument Verification

0.1 The recursion

Throughout we use the convention fixed in Paper XXXII (below: the P32 convention):

$$\rho_{\mathcal D}(0)=\rho_{\mathcal D}(1)=0,$$

$$\rho_{\mathcal D}(n)=\min\Bigl\{\underbrace{\rho_{\mathcal D}(n-1)+1}_{\text{successor candidate}},\ \underbrace{\min_{\substack{ab=n\\ a,b\ge2}}\bigl[\rho_{\mathcal D}(a)+\rho_{\mathcal D}(b)+2\bigr]}_{\text{factor candidate}}\Bigr\} \tag{0.1}$$

One successor step; a factor split costs two steps plus the cost of both sides. Throughout, $\log$ denotes the natural logarithm.

A notational warning. In this series $\rho_{S_D}$ denotes the complexity computed against a factor skeleton truncated at $D$ (Paper LXX). The subscript $\mathcal D$ here names the model, not a truncation. The two must not be conflated; where a skeleton is meant we always write $\rho_{S_D}$ explicitly.

Which model. The series has in fact used three distinct complexity models at different stages (§3.3). The one used here is $\mathcal D$: constant origin $\rho(1)=0$, constructors successor and multiplication. Earlier literature often wrote "$\rho_{\rm Full}$", where Full refers to a complete factor skeleton — a different axis from complete history grammar.

Antecedent, and the exact correspondence. The object studied here is not new. Dogra (2018; arXiv:1801.01360, Minimal Representations of Natural Numbers Under a Set of Operators) studies shortest symbolic representations over the operator set $O=\{1,S,\times\}$, charging one symbol each to the constant $1$, to every $S$, and to every multiplication sign. Writing $d$ for that complexity,

$$d(1)=1,\qquad d(n)=\min\Bigl\{d(n-1)+1,\ \min_{ab=n,\,a,b\ge2}\bigl[d(a)+d(b)+1\bigr]\Bigr\},$$

and therefore, exactly,

$$\boxed{\ d(n)=\rho_{\mathcal D}(n)+1\ } \tag{0.0}$$

Proof (substituting into the whole minimum, not candidate by candidate). Suppose $d(m)=\rho_{\mathcal D}(m)+1$ for all $m

$$d(n)=\min\Bigl\{\rho_{\mathcal D}(n-1)+2,\ \min_{ab=n}\bigl[\rho_{\mathcal D}(a)+\rho_{\mathcal D}(b)+3\bigr]\Bigr\}=\rho_{\mathcal D}(n)+1 .\qquad\square$$

The example given there — the shortest representation of $12$ being *SS1SSS1, eight symbols — corresponds to $\rho_{\mathcal D}(12)=7$, in agreement with the computation here. That paper further reports (Theorem 2.1, stronger statement) $d(n)\ge\frac{5}{\log4}\log n-1$, its equality characterization (Corollary, itself attributed to Matos), and the maximal representable value for each length (Theorem 2.3).

> From the point at which the series adopted the $\mathcal D$ model onward — this paper included — the complexity function studied differs from Dogra's $d$ by the additive constant $1$, and the principal statements of §2.1 already appear there. That antecedent was not cited in the papers concerned.

$$\eta(p)=\rho_{\mathcal D}(p)-\lambda\log p,\qquad h(p)=\eta(p)-\mu_{12}(p\bmod 12),$$

$$B_j=\sum_{p\in I_j}\frac{h(p)}{p},\qquad D_j=\sum_{p\in I_j}\frac{h(p)^2}{p^2},\qquad R_{\rm wt}(j)=\frac{B_j^2}{j\,D_j},\qquad m_j=\bigl|I_j\cap\mathbb P\bigr| .$$

A finite prefix does not affect the asymptotic substance of boundedness, but it does affect whether "for every $j\ge1$" is literally well formed, so the convention must be stated. Cleared denominators, and the side condition this carries. Theorem statements below always use $B_j^2\le C\,j\,D_j$ rather than $R_{\rm wt}(j)\le C$ (for the reason see Appendix B.2). > The two are equivalent conditionally on $D_j>0$ for all $j\ge2$.

The absence of a $j_0$ in the original statement only removes the need to absorb finitely many blocks; it does not remove this side condition, and nonvanishing is not claimed here to have been established.

1.1 The one unconditional load: Theorem 70.A

What it does. Theorem 70.A (Paper LXX) proves by elementary strong induction that for each $j$, if the skeleton cutoff satisfies $D\ge\sqrt{2^{j+1}}$ then $\rho_{S_D}(n)=\rho_{\mathcal D}(n)$ for all $n<2^{j+1}$. What it does not do. It does not remove the outer asymptotic universal quantifier of 59.1. Replacing $\rho_{\mathcal D}$ by $\rho_{S_{D^*(j)}}$ leaves the structure $\exists C\,\forall j$ untouched.

> Consequently: no stable picture within $j\le33$ can verify 59.1. Closure requires a structural theorem.

〔A reading has appeared within the series to the effect that reduction to a finite skeleton lowers the arithmetical complexity of the proposition. That is incorrect, for the reason just given, and the misreading should be denied explicitly in the text.〕

It fails in neither direction. Should 59.1 turn out to be false, Theorem 70.A converts from a reduction of the proof into a reduction of the counterexample: unboundedness would already occur within this explicit, blockwise finite family of skeletons. 2.1.1 Normalization

Definition 2.1. Set

$$c(n):=\rho_{\mathcal D}(n)+2 .$$

Substituting into (0.1),

$$c(n)=\min\Bigl\{\,c(n-1)+1,\ \min_{\substack{ab=n\\ a,b\ge2}}\bigl[c(a)+c(b)\bigr]\Bigr\} \tag{2.1}$$

The cost of a factor candidate becomes additive in $c$: the candidate value is exactly $c(a)+c(b)$, the $+2$ of the original having been absorbed by the normalization. In particular

$$c(ab)\le c(a)+c(b)\qquad (a,b\ge2). \tag{2.2}$$

〔A limit on phrasing. (2.2) must not be abbreviated to "$c$ is strictly additive on products". It is an inequality; the optimum need not attain it, and the necessary and sufficient condition for equality is not determined here.〕

Small values: $c(1)=2$, $c(2)=3$, $c(3)=4$, $c(4)=5$.

2.1.2 The global lower bound

Theorem 74.A. Put

$$\alpha:=\frac{5}{\log4}=3.606737602\ldots$$

Then for every integer $n\ge1$,

$$c(n)\ \ge\ \alpha\log n . \tag{2.3}$$

Proof. Strong induction on $n$.

Base. $n=1$: $c(1)=2\ge0$. $n=2$: $c(2)=3\ge\alpha\log2=2.5000$. $n=3$: $c(3)=4\ge\alpha\log3=3.9624$. $n=4$: $c(4)=5=\alpha\log4$, with equality.

Step. Let $n\ge5$ and suppose (2.3) holds for every $1\le m

Successor candidate: by hypothesis $c(n-1)\ge\alpha\log(n-1)$, so

$$c(n-1)+1\ \ge\ \alpha\log(n-1)+1\ \ge\ \alpha\log n ,$$

the last step requiring only $1\ge\alpha\log\frac{n}{n-1}$. Since $n\mapsto\log\frac{n}{n-1}$ decreases for $n\ge5$, the maximum is at $n=5$, where

$$\alpha\log\tfrac54=3.6067\times0.223144=0.80478<1 .$$

Factor candidate: let $n=ab$ with $a,b\ge2$; then $a,b

$$c(a)+c(b)\ \ge\ \alpha\log a+\alpha\log b\ =\ \alpha\log(ab)\ =\ \alpha\log n .$$

2.1.3 Exact values and the liminf

2.1.3a Equality rigidity

Theorem 74.A′. For $n\ge1$: $\ c(n)=\alpha\log n\iff n=4^k$ for some $k\ge1$.

Proof. ($\Leftarrow$) Corollary 74.A.1.

($\Rightarrow$) Strong induction. For $n=1,2,3$ the inequality is strict ($2>0$, $3>2.500$, $4>3.962$); at $n=4$ equality holds. Let $n\ge5$ with equality. The successor candidate is strictly above the bound: $c(n-1)+1\ge\alpha\log(n-1)+1>\alpha\log n$, strictness coming from $1>\alpha\log\frac{n}{n-1}$, whose maximum over $n\ge5$ is $0.8048$. So equality cannot come from the successor candidate. Hence $n=ab$ with $a,b\ge2$ and $c(a)+c(b)=\alpha\log a+\alpha\log b$; by Theorem 74.A both differences $c(a)-\alpha\log a$ and $c(b)-\alpha\log b$ are nonnegative and sum to zero, hence each vanishes. 2.1.4 The capacity constant

Corollary 74.A.2. For integers $K\ge2$ set

$$A(K):=\max\{\,n\ge1:\ c(n)\le K\,\}.$$

The maximum exists: the set is nonempty (it contains $n=1$, since $c(1)=2\le K$) and bounded by Theorem 74.A ($c(n)\le K$ forces $\log n\le K/\alpha$). Then for $K,L\ge2$

$$A(K+L)\ \ge\ A(K)\,A(L), \tag{2.5a}$$

and

$$\gamma:=\lim_{K\to\infty}\frac{\log A(K)}{K}=\sup_{K\ge2}\frac{\log A(K)}{K}=\frac{\log4}{5}=\frac1\alpha . \tag{2.6}$$

Proof. For (2.5a) write $a=A(K)$, $b=A(L)$. If $a,b\ge2$ then $c(ab)\le c(a)+c(b)\le K+L$ by (2.2), so $ab\le A(K+L)$. If $a=1$ then $A(K)A(L)=A(L)\le A(K+L)$ since $A$ is nondecreasing; similarly for $b=1$.

For (2.6): by (2.5a), $K\mapsto\log A(K)$ is superadditive for $K\ge2$, and Fekete's lemma (in its eventually superadditive form, since (2.5a) is stated only for $K,L\ge2$) gives existence of the limit and its equality with the supremum. Upper bound: Theorem 74.A gives $\log A(K)\le K/\alpha$, so the supremum is at most $1/\alpha$. Lower bound: by Corollary 74.A.1, $c(4^k)=5k$, so $A(5k)\ge4^k$ and

$$\frac{\log A(5k)}{5k}\ \ge\ \frac{k\log4}{5k}=\frac1\alpha .\qquad\square$$

Corollary 74.A.2′ (exact capacity points). For $k\ge1$: $\ A(5k)=4^k$.

Proof. $c(n)\le5k$ with Theorem 74.A gives $\alpha\log n\le5k$, i.e. $\log n\le5k/\alpha=k\log4$, so $n\le4^k$; and $c(4^k)=5k$ shows the value is attained. $\square$ 〔Grade C check: exact for $k=1,\ldots,8$.〕

Register. $\gamma$ is the capacity constant of this min-plus weighted grammar: it measures the exponential growth rate of the largest integer reachable within a given budget $K$. It is the reciprocal of $\alpha$.

〔Its independence must be located precisely. The existence of $\gamma$ follows from the superadditivity (2.5a) together with Fekete, a source independent of the induction of Theorem 74.A; but its exact value uses Theorem 74.A for the upper bound and $c(4^k)=5k$ — itself a consequence of 74.A — for the lower. §2.3 An exact identity and centering rigidity

2.3.1 The identity

In the notation of §0.2, set for each block

$$H_{1,j}=\sum_{p\in I_j}\frac1p,\qquad H_{2,j}=\sum_{p\in I_j}\frac1{p^2},$$

$$\bar f^{(1)}_j=\frac{1}{H_{1,j}}\sum_{p\in I_j}\frac{h(p)}{p},\qquad Q^{(2)}_j=\frac{1}{H_{2,j}}\sum_{p\in I_j}\frac{h(p)^2}{p^2},$$

so that $\bar f^{(1)}_j$ is the $1/p$-weighted mean of $h$ and $Q^{(2)}_j$ the $1/p^2$-weighted mean of $h^2$.

Proposition 74.0 (identity). Whenever $D_j\ne0$,

$$\boxed{\ R_{\rm wt}(j)=\frac{H_{1,j}^2}{j\,H_{2,j}}\cdot\frac{\bigl(\bar f^{(1)}_j\bigr)^2}{Q^{(2)}_j}\ } \tag{2.9}$$

Proof. By definition $B_j=H_{1,j}\bar f^{(1)}_j$ and $D_j=H_{2,j}Q^{(2)}_j$; substitute into $R_{\rm wt}=B_j^2/(jD_j)$. $\square$

〔Grade T1. This is a rearrangement of definitions, with no hypotheses. Its value lies precisely there: it decomposes $R_{\rm wt}$ into a purely arithmetic factor $H_{1,j}^2/(jH_{2,j})$ and a purely statistical factor $(\bar f^{(1)}_j)^2/Q^{(2)}_j$, and the separation depends on no block-internal independence or distributional assumption whatever.〕

Asymptotics. By Mertens' theorem and the prime number theorem, $H_{1,j}\sim1/j$ and $H_{2,j}\sim\bigl(2^{j+1}j\log2\bigr)^{-1}$, so

$$\frac{H_{1,j}^2}{j\,H_{2,j}}\ \sim\ 2\log2\cdot\frac{2^j}{j^2}. \tag{2.10}$$

〔Grade C check: for $j=18,\ldots,27$ the ratio of the left factor of (2.9) to the right-hand side of (2.10) runs $0.970\to0.980$, increasing monotonically toward $1$.〕

2.4.2 Uniqueness

Proposition 74.C. Fix the four real values of $\mu_{12}$. Then there is at most one $\lambda\in\mathbb R$ for which there exist $M<\infty$ and $j_0$ with

$$B_j(\lambda)^2\ \le\ M\,j\,D_j(\lambda)\qquad\text{for all }j\ge j_0 . \tag{2.13a}$$

〔The cleared-denominator form is used (Appendix B.2): $R_{\rm wt}$ involves a division, and "$D_j\ne0$" is $\Sigma^0_1$ rather than decidable for computable reals; (2.13a) is everywhere well defined and equivalent to $R_{\rm wt}\le M$ where $D_j>0$, with the proof unchanged. Proof. In four steps.

Step 1 ($jD_j\to0$, unconditional). For $p\in I_j$, Lemma 74.C.0 gives

$$|h(p)|=\bigl|\rho_{\mathcal D}(p)-\lambda\log p-\mu_{12}(p\bmod12)\bigr|=O(\log p)=O(j),$$

$$D_j(\lambda)=\sum_{p\in I_j}\frac{h(p)^2}{p^2}\ =\ O\bigl(2^j\cdot j^2\cdot4^{-j}\bigr)=O\bigl(j^2\,2^{-j}\bigr),$$

so $j\,D_j(\lambda)=O(j^3\,2^{-j})\to0$.

Step 2 ($B_j\to0$). If (2.13a) holds for $j\ge j_0$ then

$$|B_j(\lambda)|\le\sqrt{M\,j\,D_j(\lambda)}=O\bigl(j^{3/2}2^{-j/2}\bigr)\longrightarrow0 .$$

Step 3 (the difference). Suppose $\lambda_1\ne\lambda_2$ both satisfy the conclusion. Since $\mu_{12}$ is fixed and independent of $\lambda$, we have $h_{\lambda_1}(p)-h_{\lambda_2}(p)=-(\lambda_1-\lambda_2)\log p$, hence exactly

$$B_j(\lambda_1)-B_j(\lambda_2)=-(\lambda_1-\lambda_2)\sum_{p\in I_j}\frac{\log p}{p}. \tag{2.13}$$

Step 4 (contradiction). By the prime number theorem (the refinement of Mertens' first theorem with vanishing error),

$$\sum_{p\in I_j}\frac{\log p}{p}\ \longrightarrow\ \log2 . \tag{2.14}$$

By Step 2 the left side of (2.13) tends to $0$; by (2.14) the right side tends to $-(\lambda_1-\lambda_2)\log2\ne0$. Contradiction. $\square$

〔Grade T1, unconditional. Only Step 4 uses the prime number theorem (per (F2)); Steps 1–3 are elementary.〕

〔Grade C check: the deviation in (2.14) is below $2.2\times10^{-4}$ for $j=20,\ldots,23$.〕

§2.5 Unidentifiability and operational irreproducibility

2.5.1 Three items

§2.3 shows that 59.1 requires the centering constant to precision $|\varepsilon|/\sqrt{Q^{(2)}_{32}}\lesssim3.0\times10^{-5}$. This section shows in three ways that the requirement cannot currently be met:

  • (a) Extrapolative unidentifiability — within the present data window and the family of models tested, the attainable precision on $\lambda$ is three orders of magnitude short, and improves very slowly with data;
  • (b) Operational irreproducibility — the published specification fixes neither values, nor error bounds, nor an estimation procedure for $\mu_{12}$, so Table 1 of Paper LIX cannot be reproduced from the published text alone;
  • (c) The calibration enters the observable — the position of the deep trough in the $R_{\rm wt}$ profile is controlled at least in part by the calibration cutoff, not by $\rho_{\mathcal D}$ alone.

The three differ in kind: (a) is an extrapolation limit within the present window and model family; (b) concerns the operability of this particular specification; (c) concerns the constitution of the observable itself.

〔The strength of (a) must be fixed. It is not a minimax impossibility theorem over all estimation procedures, nor has it been shown that further data can never separate the models. Only the restricted form above is supported here.〕

2.5.2 (a) Extrapolative unidentifiability

Block-optimal centers. With $\mu_{12}$ fixed, let $\lambda_j^*$ be the unique $\lambda$ with $B_j(\lambda)=0$ ($B_j$ being affine in $\lambda$, so $\lambda_j^*=B_j(0)/\sum_{I_j}\frac{\log p}{p}$). Put $I_j(M)=\{\lambda:B_j(\lambda)^2\le M\,j\,D_j(\lambda)\}$ in cleared form. This set is defined by a quadratic inequality in $\lambda$, and depending on the sign of the leading coefficient $S_j^2-MjQ_2$ it may be an interval, a half-line, or a pair of rays; throughout this paper we take the connected component containing $\lambda_j^*$ and record its half-width.

〔It may not simply be called an interval: the solution set of a general quadratic inequality can be a pair of rays.〕

By Step 1 of §2.4.2 the half-width of $I_j(M)$ has exponential factor $2^{-j/2}$, together with an at most polynomial prefactor ($j^{3/2}$ from the elementary bound). Grade C check: over $j=14,\ldots,27$, fourteen blocks, the blockwise ratio lies in $0.705$–$0.719$, against $2^{-1/2}=0.7071$.

Two propositions must first be separated. The center of the original 59.1 is already specified ($\lambda=3.856763$ and the corresponding $\mu_{12}$); "there exists some $\lambda$ making the weighted ratio bounded" is a weaker existential statement. The two must not be conflated. Put

$$\mathcal E(\vec\mu)\ :=\ \exists\lambda\in\mathbb R\ \exists C>0\ \forall j\ge2:\ B_j(\lambda,\vec\mu)^2\le C\,j\,D_j(\lambda,\vec\mu).$$

§2.6 Uniqueness of the class-mean gauge

2.6.1 The definition in Paper L

Paper L §2.2 defines, for $r\in\{1,5,7,11\}$,

$$\mu_{12}(r)\ :=\ \lim_{X\to\infty}\ \frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r\ (12)}}\eta(p),\qquad \eta(p)=\rho_{\mathcal D}(p)-\lambda\log p . \tag{2.16}$$

The existence of these four limits is not proved there. This section examines what their existence constrains about $\lambda$.

2.6.2 The uniqueness theorem

Notation. For $r\in\{1,5,7,11\}$, $\lambda\in\mathbb R$ and $X\ge13$ (so that $\pi_r(X)>0$ in all four classes), set

$$M_r(X;\lambda)=\frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r\,(12)}}\bigl(\rho_{\mathcal D}(p)-\lambda\log p\bigr),\qquad L_r(X)=\frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r\,(12)}}\log p .$$

Proposition 74.D. For $\lambda_1\ne\lambda_2$, exactly

$$M_r(X;\lambda_1)-M_r(X;\lambda_2)=-(\lambda_1-\lambda_2)\,L_r(X), \tag{2.17}$$

and by the prime number theorem for arithmetic progressions $L_r(X)\sim\log X\to\infty$. Therefore:

> For each $r$, at most one $\lambda$ can make $M_r(X;\lambda)$ converge to a finite real. In particular at most one common $\lambda$ can make all four $\mu_{12}(r)$ of (2.16) simultaneously well posed.

Proof. (2.17) is immediate on subtracting the definitions (the $\rho_{\mathcal D}(p)$ terms cancel). For $L_r$: by the prime number theorem in arithmetic progressions, $\sum_{p\le X,\,p\equiv r}\log p\sim X/\varphi(12)$ while $\pi_r(X)\sim X/(\varphi(12)\log X)$, so $L_r(X)\sim\log X$. Now suppose $\lambda_1\ne\lambda_2$ and both $M_r(X;\lambda_1)$ and $M_r(X;\lambda_2)$ converge to finite reals. Then so does their difference; but by (2.17) that difference equals $-(\lambda_1-\lambda_2)L_r(X)$, whose absolute value tends to $+\infty$. Contradiction. $\square$

〔Grade T1, unconditional. External result invoked: the prime number theorem for arithmetic progressions (per (F2)).〕

Summary sentence.

> Well-posedness of $\mu_{12}$ forces the centering slope to be unique; but uniqueness of the centering slope does not by itself deliver $\mu_{12}$.

2.6.3 The direction not claimed here

Suppose a prime-side slope $\lambda_*$ exists in some sense, say

$$\frac{1}{L_r(X)}\cdot\frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r}}\rho_{\mathcal D}(p)\ \longrightarrow\ \lambda_* . \tag{2.18}$$

Convergence of $M_r(X;\lambda_*)$ does not follow from (2.18). All that (2.18) yields is

$$M_r(X;\lambda_*)=o\bigl(L_r(X)\bigr)=o(\log X),$$

and $o(\log X)$ entails neither $O(1)$ nor convergence.

An abstract counterexample. Suppose

$$\frac{1}{\pi_r(X)}\sum_{p\le X,\ p\equiv r}\rho_{\mathcal D}(p)\ =\ \lambda_*L_r(X)+\sqrt{L_r(X)} .$$

Then (2.18) holds, while $M_r(X;\lambda_*)=\sqrt{L_r(X)}\to+\infty$: the centered class mean diverges.

Probability space (must be explicit). Let $\mathcal C_N=\{2\le n\le N: n\ \text{composite}\}$, and let $\mathbb P_N,\mathbb E_N$ denote the uniform probability and expectation on $\mathcal C_N$. All conditional quantities below refer to that measure.

Let the jump quantity be

$$J(n):=\rho_{\mathcal D}(n-1)+1-\rho_{\mathcal D}(n)\ \ge\ 0$$

(nonnegativity from the successor candidate). Telescoping gives exactly

$$\sum_{n=2}^{N}J(n)=N-1-\rho_{\mathcal D}(N)=N+O(\log N), \tag{3.1}$$

2.1.4 容量常数

推论 74.A.2. 对整数 $K\ge2$ 定义

$$A(K):=\max\{\,n\ge1:\ c(n)\le K\,\}.$$

该最大值存在：集合非空（含 $n=1$，因 $c(1)=2\le K$），且由定理 74.A 有界（$c(n)\le K\Rightarrow\log n\le K/\alpha$）。则对 $K,L\ge2$

$$A(K+L)\ \ge\ A(K)\,A(L), \tag{2.5a}$$

且

$$\gamma:=\lim_{K\to\infty}\frac{\log A(K)}{K}=\sup_{K\ge2}\frac{\log A(K)}{K}=\frac{\log4}{5}=\frac1\alpha . \tag{2.6}$$

证. (2.5)：记 $a=A(K)$，$b=A(L)$。若 $a,b\ge2$，由 (2.2) 得 $c(ab)\le c(a)+c(b)\le K+L$，故 $ab\le A(K+L)$。若 $a=1$（即 $A(K)=1$），则 $A(K)A(L)=A(L)\le A(K+L)$，因 $A$ 非降。$b=1$ 同理。

(2.6)：由 (2.5)，$K\mapsto\log A(K)$ 在 $K\ge2$ 上超可加，Fekete 引理（超可加形式）给出极限存在并等于上确界。上界：定理 74.A 给 $\log A(K)\le K/\alpha$，故 $\sup\le1/\alpha$。下界：由推论 74.A.1，$c(4^k)=5k$，故 $A(5k)\ge4^k$，于是

$$\frac{\log A(5k)}{5k}\ \ge\ \frac{k\log4}{5k}=\frac{\log4}{5}=\frac1\alpha .$$

两侧相等。$\square$

〔档：T1；外部引用 Fekete 引理（超可加形式），依 (F2)。〕

推论 74.A.2′（精确容量点）. 对 $k\ge1$：$\ A(5k)=4^k$。

$$c(2^m)-c(2^{m-1})=\begin{cases}1,& m=1\\[2pt] 2,& m\ge2\ \text{为偶数}\\[2pt] 3,& m\ge3\ \text{为奇数}\end{cases} \tag{2.8}$$

记 $m\ge2$ 时的取值为 $c_\Delta(m)$。

读法. 除初始步外，进入偶数 $m$ 的增量为 $2$，进入奇数 $m$ 的增量为 $3$。机制是：$2^{\text{偶}}$ 可整分为若干个 $4$，而 $c(4)/2=2.5$ 是每个二倍的最低成本；$2^{\text{奇}}$ 必余一个孤立的 $2$，其成本为 $3$。

〔$m=1$ 的例外须写明。它不影响本文第四部分（相关增量自 $m\ge2$ 起），但定理文字须准确。〕

§2.2 两个斜率：$h_0$ 与 $\lambda$

2.2.1 文献中的两个常数

Paper 32 §3 使用常数 $h_0$，由该处的 $h_0\log2=2.48$ 得 $h_0=3.578$。Paper 59 §2.1 使用 $\lambda=3.856763$，并称之为「P32 约定」下的取值。Paper 50 §1.2 引用 P32 约定时写 $\lambda\approx3.86$。

本文的观察是：$h_0$ 与 $\lambda$ 是两个不同的常数，服务于不同的对象。

C 档实测（自建表，(F3)）：

$$\frac{\rho_{\mathcal D}(10^7)}{\log10^7}=3.5984,\qquad \frac{\rho_{\mathcal D}(10^8)}{\log10^8}=3.5829 .$$

二者与 $h_0=3.578$ 相合，与 $\lambda=3.856763$ 不合。故 $h_0$ 是全体整数在该有限尺度上的校准量，而 $\lambda$ 是素数层使用的中心化系数（见 §0.2 中 $\eta(p)=\rho_{\mathcal D}(p)-\lambda\log p$ 的定义）。

2.2.2 与定理 74.A 的相容性

上述实测值低于 $\alpha=3.6067$。这与定理 74.A 不矛盾：定理对 $\rho_{\mathcal D}/\log n$ 给出的有限尺度下界是

$$\frac{\rho_{\mathcal D}(n)}{\log n}\ \ge\ \alpha-\frac{2}{\log n},$$

在 $n=10^8$ 处为 $3.6067-0.1086=3.498$，而实测 $3.5829\ge3.498$。

〔措辞限定：只可写「不与定理矛盾」，不可写「低于 $\alpha$ 仅因 $c=\rho+2$ 的偏移」。「相容」由上式挣得；「仅因」蕴含对差额来源的完整归因，本文未作此论证。〕

2.2.3 与 prime penalty 的关系

Paper 32 §3 登记了一般整数与素数的残差差异（$E[R(p)]=4.57$ 对 $E[R(n)]=2.76$，差约 $1.81$），并命名为 prime penalty。

精确关系（由附录 A.1.1 的澄清得出）. $h_0$ 是单点比值 $\rho_{\mathcal D}(N)/\log N$；$\lambda$ 是带截距 OLS 的斜率。二者由截距项精确相差：

$$\frac{\rho_{\mathcal D}(N)}{\log N}=\lambda+\frac{\mu_N}{\log N},\qquad \mu_N:=\rho_{\mathcal D}(N)-\lambda\log N . \tag{2.5}$$

〔这是定义恒等式，不是独立核验：$h_0:=\rho_{\mathcal D}(N)/\log N$，故 $\lambda-h_0=-\mu_N/\log N$ 恒成立，(2.5b) 只是该定义的代数分解。数值示例（$N=10^8$）：$\rho_{\mathcal D}=66$，$\mu_N=-5.0405$，$\mu_N/\log N=-0.27363$，$\lambda-h_0=0.27386$，其差仅为 $h_0$ 的舍入。须留意：$\mu_N$ 是该点的残差，非 OLS 截距；(2.5b) 是定义的代数分解，不构成独立核验。〕

〔prime penalty 降为旁注：Paper 32 §3 所记的残差差（约 $1.81$）为「素数构造成本系统性偏高」提供定性背景，但 (2.5) 已给出 $h_0$ 与 $\lambda$ 之差的精确来源，不再需要经由它作解释。二者亦不得等同：$\lambda-h_0\approx0.279$ 是斜率与单点比值之差，与残差均值差量纲不同。〕

2.2.4 全 $n$ 极限的唯一可能值

推论 74.B. 若 $\lim_{n\to\infty}\dfrac{\rho_{\mathcal D}(n)}{\log n}$ 存在，则它等于 $\dfrac{5}{\log4}=3.6067\ldots$

证. 极限存在时必等于 $\liminf$，由推论 74.A.1 即 $5/\log4$。$\square$

〔档：T1，以「该极限存在」为假设（(F2) 意义下的前提冻结）。本推论不证明该极限存在。〕

登记. 本推论精确限定了全 $n$ 极限唯一可能的取值，与 §2.2.1 的观察相合：$\lambda=3.856763$ 从来不是全 $n$ 极限的候选，上游文献亦未如此使用它。

须同时写出的开放项：素数子列上的极限

$$\lim_{p\to\infty,\ p\ \text{素}}\frac{\rho_{\mathcal D}(p)}{\log p}$$

的存在性未证，而这正是 §0.2 中 $\eta$ 与 $\mu_{12}$ 的定义所依赖的那一个。定理 74.A 的方法对它不可用：其归纳的因子候选步在素数处退化为空真（$p$ 的因子只有 $1$ 与 $p$，而 (2.1) 要求 $a,b\ge2$），全部承重落到后继候选，而后继候选只给逐点递推、不给渐近。

〔参照：整数复杂度 $\|n\|$ 的 $\liminf$ 与 $\limsup$ 至今分离，是同一缺口的经典形态。〕

§2.3 精确恒等式与中心化刚性

2.3.1 恒等式

沿 §0.2 的记号。对每个块 $I_j$ 令

$$H_{1,j}=\sum_{p\in I_j}\frac1p,\qquad H_{2,j}=\sum_{p\in I_j}\frac1{p^2},$$

$$\bar f^{(1)}_j=\frac{1}{H_{1,j}}\sum_{p\in I_j}\frac{h(p)}{p},\qquad Q^{(2)}_j=\frac{1}{H_{2,j}}\sum_{p\in I_j}\frac{h(p)^2}{p^2},$$

即 $\bar f^{(1)}_j$ 为 $h$ 的 $1/p$-加权均值，$Q^{(2)}_j$ 为 $h^2$ 的 $1/p^2$-加权均值。

命题 74.0（恒等式）. 只要 $D_j\ne0$，

$$\boxed{\ R_{\rm wt}(j)=\frac{H_{1,j}^2}{j\,H_{2,j}}\cdot\frac{\bigl(\bar f^{(1)}_j\bigr)^2}{Q^{(2)}_j}\ } \tag{2.9}$$

证. 由定义 $B_j=H_{1,j}\bar f^{(1)}_j$、$D_j=H_{2,j}Q^{(2)}_j$，代入 $R_{\rm wt}=B_j^2/(jD_j)$。$\square$

〔档：T1。这是定义的重排，无任何假设。其价值正在于此：它把 $R_{\rm wt}$ 分解为一个纯算术因子 $H_{1,j}^2/(jH_{2,j})$ 与一个纯统计因子 $(\bar f^{(1)}_j)^2/Q^{(2)}_j$，二者的分离不依赖块内独立性或任何分布假定。〕

渐近. 由 Mertens 定理与素数定理，$H_{1,j}\sim1/j$ 且 $H_{2,j}\sim\bigl(2^{j+1}j\log2\bigr)^{-1}$，故

$$\frac{H_{1,j}^2}{j\,H_{2,j}}\ \sim\ 2\log2\cdot\frac{2^j}{j^2}. \tag{2.10}$$

〔C 档核验：$j=18,\ldots,27$ 上 (2.9) 左因子与 (2.10) 右端之比为 $0.970\to0.980$，单调趋 $1$。〕

2.3.2 三种残差结构下的尺度

由 (2.9)，$R_{\rm wt}$ 的行为完全由统计因子 $(\bar f^{(1)}_j)^2/Q^{(2)}_j$ 决定。三种典型结构：

# 残差结构 $(\bar f^{(1)})^2/Q^{(2)}$ $R_{\rm wt}$ 的尺度 对 59.1
1$h$ 含非零一致块均值 $m_j\to m\ne0$$\to\dfrac{m^2}{m^2+\sigma^2}$，常数$\asymp2^j/j^2$假
2$h$ 含缓慢增长的一致块均值 $m_j\to\infty$$\to1$$\asymp2^j/j^2$假
3加权均值为零的伪随机波动$\approx H_{2,j}/H_{1,j}^2$$O_{\mathbb P}(1/j)$真

〔档：T2（对既有结果的重新框定）。三行是模型解释，不是恒等式的推论；恒等式本身为 T1（§2.3.1）。二者须分档。〕

两处须留意的技术点.

其一，第 2 行不含额外的 $\log^2j$ 因子。若 $h(p)=m_j+\xi_p$ 且 $m_j\asymp\log j$、$\xi$ 的加权二阶矩有界，则 $Q^{(2)}_j\asymp m_j^2+\operatorname{Var}(\xi)$ 与 $(\bar f^{(1)}_j)^2\asymp m_j^2$ 同阶，比值 $\to1$，主尺度仍是 $2^j/j^2$。$\log^2j$ 只在把 $Q^{(2)}$ 误读为中心化方差时出现；而 $D_j$ 用的是未中心化二阶矩。结论（59.1 为假）不变，增长率须按上表。

其二，第 3 行的常数不写死。在独立、加权均值为零、同方差的模型中 $E[B_j^2]\approx\sigma^2H_{2,j}$ 而 $D_j\approx\sigma^2H_{2,j}$，故典型尺度为 $R_{\rm wt}=O_{\mathbb P}(1/j)$，一阶期望常数接近 $1$。不得把某一随机模型的常数写成确定结论。

2.3.3 中心化刚性

由上表第 1、2 行：

> 精确中心化是 59.1 的必要条件，且要求极端刚性。

同时须写出其界限：

> 即使中心化完全正确（即统计因子的分子被压到伪随机尺度），59.1 仍另外要求块和具有足够取消。 中心化正确不蕴含 59.1。

2.3.4 由已发表数据反推的精度要求

设 $\lambda$ 的登记值与真值差 $\varepsilon$。则 $h$ 获得增量 $-\varepsilon\log p$，故

$$\bar f^{(1)}_j\ \longmapsto\ \bar f^{(1)}_j-\varepsilon\cdot\frac{1}{H_{1,j}}\sum_{p\in I_j}\frac{\log p}{p}\ \approx\ \bar f^{(1)}_j-\varepsilon\,(j+\tfrac12)\log2 . \tag{2.11}$$

该增量与 $j$ 成正比，而 (2.10) 的算术因子按 $2^j/j^2$ 增长。

Paper 59 表 1 给出 $j=14,\ldots,32$ 的 $R_{\rm wt}$ 实测值。其中约束最紧的一块是 $j=32$（$R_{\rm wt}=2.70$，非全表最大值 $25.80$）：代入 (2.9)–(2.11)，

$$\boxed{\ \Bigl|\frac{\varepsilon}{\sqrt{Q^{(2)}_{32}}}\Bigr|\ \lesssim\ 3.0\times10^{-5}\ } \tag{2.12}$$

换算为绝对界（须条件式陈述）. $\sqrt{Q^{(2)}_j}$ 是 $h$ 的 $1/p^2$-加权二阶矩之根。C 档实测（本文截断口径，$j=18\ldots27$）：$0.7356\to0.7551$，单调缓升，末四块均值 $0.7523$。若 $\sqrt{Q^{(2)}_{32}}$ 与之同量级（取 $0.75$），则

$$|\varepsilon|\ \lesssim\ 2.3\times10^{-5}. \tag{2.12b}$$

〔该换算是条件式的：$Q^{(2)}_{32}$ 在 Paper 59 的标定口径下未发表，本文以自身截断口径的趋势外推。全文凡以「数量级」比较绝对量者（§2.5.2 的 $0.05$、§2.6.4 的 $0.0153$），皆须经 (2.12b) 换算，且其倍数依赖该外推。〕

〔档：T2-条件项。三项限定：(a) 主形式须写成比值——绝对界依赖 $\sqrt{Q^{(2)}_{32}}$；(b) 该反推假设其余块均值误差已被正确消除，不能无条件把整个 $\bar f^{(1)}$ 归因于 $\lambda$；(c) 用的是 (2.10) 的渐近，$j=32$ 处的算术因子实际比渐近值低约 $2\%$，故 (2.12) 略偏保守。〕

2.3.5 附带：Bartlett 族失败的第二条理由

P73 §7.5 记录：正则模型内带宽包络为 $m_j^{0.33}\lesssim F_W\lesssim m_j^{0.63}$，而闭合需 $O(\log m_j)$，并把该失败读作多项式对对数的差距。

〔本文不主张 P73 §7.5 的原论证有误——它在自己的框架内成立。本文主张该结论有第二条更粗的来源，且先于任何窗口选择。两条互不相干的路径给出同一结论，其稳健性高于任一单条。〕

§2.4 标定唯一性

2.4.1 一条初等上界

引理 74.C.0. 对一切 $m\ge2$，

$$\rho_{\mathcal D}(2m)\le\rho_{\mathcal D}(m)+3,\qquad \rho_{\mathcal D}(2m+1)\le\rho_{\mathcal D}(m)+4 .$$

因此 $\rho_{\mathcal D}(n)=O(\log n)$；具体地 $\rho_{\mathcal D}(n)\le4\log_2n$ 对 $n\ge2$。

证. 由 (2.1) 的因子候选取 $a=2$、$b=m$（皆 $\ge2$）：$\rho_{\mathcal D}(2m)\le\rho_{\mathcal D}(2)+\rho_{\mathcal D}(m)+2=\rho_{\mathcal D}(m)+3$。再由后继候选 $\rho_{\mathcal D}(2m+1)\le\rho_{\mathcal D}(2m)+1$。对 $n$ 的二进制展开逐位递推即得 $O(\log n)$。$\square$

〔档：T1，初等。C 档核验：$n\le2^{17}$ 上 $\max_n\rho_{\mathcal D}(n)/\log n=4.126$。〕

〔方法登记：Paper 59 §7.1 由「Guy 界＋Chebyshev」得到 $D_j\le C'j/2^j$。本引理经块内计数上界给出同型结论而不调用素数计数，见下。这不是新结果，是更省的路线。〕

2.4.2 唯一性

命题 74.C. 固定 $\mu_{12}$ 的四个实数值。则至多存在一个 $\lambda\in\mathbb R$，使得存在 $M<\infty$ 与 $j_0$ 满足

$$B_j(\lambda)^2\ \le\ M\,j\,D_j(\lambda)\qquad\text{对一切 }j\ge j_0 . \tag{2.13a}$$

〔采用清分母写法（附录 B.2）：$R_{\rm wt}$ 含除法，而「$D_j\ne0$」对可计算实数是 $\Sigma^0_1$ 而非可判定；(2.13a) 处处良定义，在 $D_j>0$ 时与 $R_{\rm wt}\le M$ 等价，证明完全不变。建议 59.1 的正式定理版本亦以清分母式为主，$R_{\rm wt}$ 只保留作诊断量名称。〕

证. 分四步。

第一步（$jD_j\to0$，无条件）. 对 $p\in I_j$，由引理 74.C.0，

$$|h(p)|=\bigl|\rho_{\mathcal D}(p)-\lambda\log p-\mu_{12}(p\bmod12)\bigr|=O(\log p)=O(j),$$

而 $p^{-2}\le4^{-j}$，且 $I_j$ 中的整数不超过 $2^j$ 个（只用区间长度，不需素数计数）。故

$$D_j(\lambda)=\sum_{p\in I_j}\frac{h(p)^2}{p^2}\ =\ O\bigl(2^j\cdot j^2\cdot4^{-j}\bigr)=O\bigl(j^2\,2^{-j}\bigr),$$

于是 $j\,D_j(\lambda)=O(j^3\,2^{-j})\to0$。

第二步（$B_j\to0$）. 若 (2.13a) 于 $j\ge j_0$ 成立，则

$$|B_j(\lambda)|\le\sqrt{M\,j\,D_j(\lambda)}=O\bigl(j^{3/2}2^{-j/2}\bigr)\longrightarrow0 .$$

第三步（差式）. 设 $\lambda_1\ne\lambda_2$ 皆满足结论。$\mu_{12}$ 固定不依赖 $\lambda$，故 $h_{\lambda_1}(p)-h_{\lambda_2}(p)=-(\lambda_1-\lambda_2)\log p$，于是精确地

$$B_j(\lambda_1)-B_j(\lambda_2)=-(\lambda_1-\lambda_2)\sum_{p\in I_j}\frac{\log p}{p}. \tag{2.13}$$

第四步（矛盾）. 由素数定理（Mertens 第一定理的带余项精化），

$$\sum_{p\in I_j}\frac{\log p}{p}\ \longrightarrow\ \log2 . \tag{2.14}$$

由第二步，(2.13) 的左端 $\to0$；由 (2.14)，右端 $\to-(\lambda_1-\lambda_2)\log2\ne0$。矛盾。$\square$

〔档：T1，无条件。外部引用仅第四步的 (2.14)（依 (F2)），前三步全部初等。〕

〔C 档核验：(2.14) 于 $j=20,\ldots,23$ 处偏差皆小于 $2.2\times10^{-4}$。〕

§2.5 不可辨识性与操作性不可复现

2.5.1 本节的三项内容

§2.3 表明 59.1 对中心化常数的精度要求是 $|\varepsilon/\sqrt{Q^{(2)}_{32}}|\lesssim3.0\times10^{-5}$。本节从三个方向说明该要求当前无法满足：

  • (a) 外推不可辨识：在当前数据窗口与所检验的模型族内，可确定的 $\lambda$ 精度比要求低三个数量级，且随数据量增加改善极慢；
  • (b) 操作性不可复现：已发表规范未固定 $\mu_{12}$ 的取值、误差界或估计程序，故 Paper 59 表 1 不能由已发表文本单独复现。
  • (c) 标定进入观测量：$R_{\rm wt}$ 剖面中深谷随标定截断系统迁移，故不由 $\rho_{\mathcal D}$ 与块索引单独决定；本文不作排他性因果归因。

三者性质不同：(a) 是当前数据窗口下、所检验模型族内的外推限制；(b) 是关于这一份规范的可操作性；(c) 是关于观测量本身的构成。

〔(a) 的强度须写死：它不是对一切可能估计程序的 minimax 不可能定理，亦未证明继续增加数据永远不能区分模型。本文所支持的仅为上述限定形态。〕

2.5.2 (a) 外推不可辨识

块最优常数. 固定 $\mu_{12}$，令 $\lambda_j^*$ 为使 $B_j(\lambda)=0$ 的唯一 $\lambda$（$B_j$ 是 $\lambda$ 的一次式，$\lambda_j^*=B_j(0)/\sum_{I_j}\frac{\log p}{p}$）。令 $I_j(M)=\{\lambda:B_j(\lambda)^2\le M\,j\,D_j(\lambda)\}$（清分母形式）。该集合由一个 $\lambda$ 的二次不等式定义，其解集视二次项系数 $S_j^2-MjQ_2$ 的符号可为区间、半线或两条射线；本文一律取含 $\lambda_j^*$ 的连通分支，并记其半宽。〔不可径称「故为区间」：一般二次不等式的解集可为两条射线。〕

由 §2.4.2 第一步，$I_j(M)$ 半宽的指数因子为 $2^{-j/2}$，另带至多多项式前因子（初等界给 $j^{3/2}$）。C 档核验：$j=14,\ldots,27$ 共 14 块，逐块半宽比落在 $0.705$–$0.719$，对照 $2^{-1/2}=0.7071$。

由此得一条平凡等价与一条必要条件。

须先分离两个命题. 原 59.1 的中心是已指定的（$\lambda=3.856763$ 及相应 $\mu_{12}$）；而「存在某个 $\lambda$ 使谱比有界」是一个更弱的存在命题。二者不可混。令

$$\mathcal E(\vec\mu)\ :=\ \exists\lambda\in\mathbb R\ \exists C>0\ \forall j\ge2:\ B_j(\lambda,\vec\mu)^2\le C\,j\,D_j(\lambda,\vec\mu).$$

则平凡等价（定义重写）为

$$\mathcal E(\vec\mu)\ \iff\ \exists C,\lambda\ \ \forall j\ge2:\ \lambda\in I_j(C). \tag{2.15}$$

而固定参数版本 $59.1_{\rm freeze}(\lambda_0,\vec q):\ \exists C>0\ \forall j\ge2:\ B_j(\lambda_0,\vec q)^2\le C\,j\,D_j(\lambda_0,\vec q)$ 与之的关系是

$$59.1_{\rm freeze}(\lambda_0,\vec q)\ \Longrightarrow\ \mathcal E(\vec q),$$

§2.6 类均值规范的唯一性

2.6.1 Paper 50 的定义

Paper 50 §2.2 定义，对 $r\in\{1,5,7,11\}$，

$$\mu_{12}(r)\ :=\ \lim_{X\to\infty}\ \frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r\ (12)}}\eta(p),\qquad \eta(p)=\rho_{\mathcal D}(p)-\lambda\log p . \tag{2.16}$$

原文未证明这四个极限存在。本节考察其存在性对 $\lambda$ 的约束。

2.6.2 唯一性定理

记号. 对 $r\in\{1,5,7,11\}$、$\lambda\in\mathbb R$、$X\ge13$（使四类 $\pi_r(X)>0$）令

$$M_r(X;\lambda)=\frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r\,(12)}}\bigl(\rho_{\mathcal D}(p)-\lambda\log p\bigr),\qquad L_r(X)=\frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r\,(12)}}\log p .$$

命题 74.D. 对任意 $\lambda_1\ne\lambda_2$，精确地

$$M_r(X;\lambda_1)-M_r(X;\lambda_2)=-(\lambda_1-\lambda_2)\,L_r(X). \tag{2.17}$$

且由算术级数素数定理 $L_r(X)\sim\log X\to\infty$。因此：

> 对每个 $r$，至多存在一个 $\lambda$ 使 $M_r(X;\lambda)$ 收敛为有限实数。特别地，至多存在一个公共 $\lambda$ 使 (2.16) 的四个极限同时良构。

证. (2.17) 直接由定义相减得出（$\rho_{\mathcal D}(p)$ 项相消）。对 $L_r$：由算术级数素数定理，$\sum_{p\le X,\,p\equiv r}\log p\sim X/\varphi(12)$ 而 $\pi_r(X)\sim X/(\varphi(12)\log X)$，故 $L_r(X)\sim\log X$。

设 $\lambda_1\ne\lambda_2$ 且 $M_r(X;\lambda_1)$、$M_r(X;\lambda_2)$ 皆收敛为有限实数。则其差收敛为有限实数。但由 (2.17) 该差等于 $-(\lambda_1-\lambda_2)L_r(X)$，其绝对值趋于 $+\infty$。矛盾。$\square$

〔档：T1，无条件。外部引用：算术级数素数定理（依 (F2)）。〕

收束句.

> $\mu_{12}$ 的良构性强制中心斜率唯一；但中心斜率唯一不自动交付 $\mu_{12}$。

2.6.3 本文明确不主张的方向

设素数侧存在某种意义的斜率 $\lambda_*$，例如

$$\frac{1}{L_r(X)}\cdot\frac{1}{\pi_r(X)}\sum_{\substack{p\le X\\ p\equiv r}}\rho_{\mathcal D}(p)\ \longrightarrow\ \lambda_* . \tag{2.18}$$

由 (2.18) 不能推出 $M_r(X;\lambda_*)$ 收敛。 (2.18) 只给

$$M_r(X;\lambda_*)=o\bigl(L_r(X)\bigr)=o(\log X),$$

而 $o(\log X)$ 既不蕴含 $O(1)$，更不蕴含收敛。

抽象反例. 设

$$\frac{1}{\pi_r(X)}\sum_{p\le X,\ p\equiv r}\rho_{\mathcal D}(p)\ =\ \lambda_*L_r(X)+\sqrt{L_r(X)} .$$

则 (2.18) 成立，而 $M_r(X;\lambda_*)=\sqrt{L_r(X)}\to+\infty$：中心化后的类均值发散。

D.2 递归不变式自检（参考实现）

用途：捕获构建器的因子表截顶、骨架不完整、索引错位一类错误。本系列的死因之一（表 1.1 第 1 条）正属此类。建议在任何新 $\rho$ 表构建后无条件执行。

不变式：对一切 $n=ab$（$a,b\ge2$，$a\le\sqrt n$）应有

$$\rho_{\mathcal D}(n)\ \le\ \rho_{\mathcal D}(a)+\rho_{\mathcal D}(n/a)+2 .$$

/* 递归不变式全表审计。O(N log N)。任何违背即表明 rho 表不是 (0.1) 的解。 */
long audit_invariant(const short *rho, long N) {
    long viol = 0;
    for (long a = 2; a * a <= N; a++)
        for (long b = a; a * b <= N; b++) {
            long n = a * b;
            if (rho[n] > rho[a] + rho[b] + 2) viol++;
        }
    return viol;   /* 应为 0 */
}

D.3 $\rho_{\mathcal D}$ 表的构建

for (long n = 2; n <= N; n++) {
    int v = rho[n-1] + 1;
    if (rho[n] < v) v = rho[n];      /* 已累积的因子候选 */
    rho[n] = v;
    long lim = N / n; if (lim > n) lim = n;
    for (long a = 2; a <= lim; a++) {
        long m = a * n;
        int c = rho[a] + v + 2;
        if (c < rho[m]) rho[m] = c;
    }
}
